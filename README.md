# Engineer — AI Engineering Assistant

A private-workflow-inspired engineering assistant plugin for ChatGPT/Codex, combining guidance for agentic software engineering, persistent chat memory, Graphify knowledge graphs, OmniRoute AI gateway setup, and Ponytail coding practices.

## Included skills

- `agent-skills` — production-oriented engineering workflows: planning, implementation, testing, review, performance, and shipping.
- `chatgpt-mem` — persistent memory setup and troubleshooting for AI coding/chat sessions.
- `graphify-knowledge-graph` — map and query codebases, documentation, schemas, and project artifacts.
- `omniroute-setup` — install, configure, secure, and troubleshoot the OmniRoute AI gateway.
- `ponytail-coding` — minimal, maintainable code and practical code review.

## Repository status

This repository is the public GitHub distribution/source location. The full plugin source and bundled skill files should be kept in their corresponding `skills/` folders, with plugin manifests in `.codex-plugin/` and the repository root.
